# CAD 画 UI 草图规范（cad2ui）

工具按这些约定识别，"照规范画 = 识别确定，不照 = 猜"。

## 图层

| 图层 | 语义 | 识别结果 |
|---|---|---|
| `UI-FRAME` | 页面外框 | `type: frame`，自动当根容器 |
| `UI-BOX` | 控件框（矩形） | 继续按块名/尺寸推断 |
| `UI-TEXT` | 文字 | `type: text` |
| `UI-LINE` | 分隔线 | `type: line` |
| `UI-FILL` | 填充区 | `type: fill`，永远不当父节点 |

辅助线、尺寸标注、引线请放在别的图层，或用 `--ignore-layers` 跳过。

## 图块命名

英文小写 + 下划线，直接用组件名：

- `btn_primary` / `btn_danger` → button
- `input_search` / `input_password` → input
- `card_task` / `card_stats` → card
- `nav_top` / `nav_side` → nav
- `icon_calendar` / `icon_arrow` → icon

词表见 `core/style.py` 的 `KEYWORDS`；不在词表里就在 `--map` 指定。

## 固定色表（ACI 1–9）

| ACI | 颜色 | 用途 |
|---|---|---|
| 1 | `#F56C6C` | 危险/删除 |
| 2 | `#E6A23C` | 警告 |
| 3 | `#67C23A` | 成功 |
| 4 | `#17BECF` | 图表 |
| 5 | `#409EFF` | 主色 |
| 6 | `#B37FEB` | 强调 |
| 7 | `#303133` | 正文 |
| 8 | `#909399` | 次要文字 |
| 9 | `#C0C4CC` | 边框/填充 |

其他索引色会变成 `#888888` 并记 `COLOR_APPROX`。

## 尺寸

- 1 图纸单位 = 1px，按 **1440 宽**画布画。
- 导出时 `--width` 只改输出画布，判定阈值会自动按比例换算。
- 常用尺寸：按钮高 32–48、卡片宽 ≥ 300、图标 < 48。

## 硬性要求

1. 控件必须是**闭合**矩形；未闭合的会当线处理。
2. 文字画在框**里面**，工具靠文字包围盒判断归属。
3. 不要用嵌套块表达层级——一个块就是最小组件。
4. 切角/异形框可以用 5 个以上顶点的闭合多段线，会保留 `points` 供 `clip-path` 使用。
5. 填充块不要盖住按钮，它会作为兄弟节点参与布局。
